# Fitness Coaching App

Application web de coaching fitness développée avec React et Django REST Framework.

## Fonctionnalités

- Authentification JWT
- Gestion des coachs
- Programmes sportifs
- Paiement de séances
- Dashboard utilisateur
- Dashboard coach
- Messagerie
- Rendez-vous
- Gestion via Django Admin

## Technologies utilisées

### Frontend
- React
- React Router
- CSS
- Fetch API

### Backend
- Django
- Django REST Framework
- JWT Authentication
- SQLite

## Architecture

Frontend React → API REST Django → Base de données SQLite

## Lancer le projet

### Backend

```bash
cd backend
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
